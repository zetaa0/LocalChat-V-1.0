# LocalChat-V-1.0

This project is a real-time multi-client chat application built entirely from scratch in Python using raw TCP sockets and multithreading to demonstrate low-level network programming concepts and concurrent client management. Because TCP treats data as a continuous stream of bytes rather than isolated packets, the application solves the common stream fragmentation and concatenation problem by implementing a custom two-step messaging protocol where every message or username payload is preceded by a fixed sixty-four-byte header string that explicitly states the length of the upcoming data so the receiver always knows exactly how many bytes to read.

The server acts as a central hub that binds to a specific host IP and port, listens for incoming TCP connections, and automatically spawns a dedicated background thread for every new user so it can manage multiple connections simultaneously without blocking. When any user sends a message, the server immediately broadcasts it to all other connected clients while skipping the original sender. On the client side, the application connects to the server IP and port, prompts the user for a username, and creates a background daemon thread that constantly listens for incoming network broadcasts while the main thread remains completely free to accept keyboard inputs from the terminal.

To run the application, you first need to open both the server and client source files and update the host variable at the bottom of the scripts to match your local network configuration, using localhost for local testing or your machine local IPv4 address if you are connecting multiple devices over the same local network. After configuring the address and port, open a terminal window to start the server by running the server script, which will display a confirmation message indicating that it is successfully listening for connections. Next, open separate terminal windows for each user you want to simulate and run the client script, type your chosen username when prompted, and you can immediately begin sending messages into the chat prompt. To leave the chat gracefully at any time, simply type the disconnect message command into the terminal, which will safely close the socket connection and clean up resources on both ends.
